# AI任务标签功能设计方案

## 需求概述
在AI任务提交时支持添加标签（日期/批次），任务列表中标签放在显眼位置，点击标签可直接过滤。

## 设计思路

### 标签存储
沿用项目已有的 `Article.Tags` 逗号分隔字符串模式，在 `AiTask` 实体上新增 `Tags` 字段（VARCHAR 200），存储格式：`"2026-07-02,批次A"`。

### 标签类型
- **日期标签**：自动从任务创建时间提取（格式 `YYYY-MM-DD`），用户也可手动选择其他日期
- **批次标签**：用户手动输入，如 `批次A`、`产品图`、`测试1` 等自由文本

## 改动清单

### 1. 后端 Model — `ZR.Model/System/Model/AiTask.cs`
新增 `Tags` 字段：
```csharp
[SugarColumn(Length = 200, IsNullable = true)]
public string Tags { get; set; }
```

### 2. 后端 DTO — `ZR.Model/System/Dto/AiTaskDto.cs`

**AiTaskSubmitDto** 新增：
```csharp
public string Tags { get; set; }
```

**AiTaskListDto** 新增筛选字段：
```csharp
public string Tag { get; set; }
```

**AiTaskUpdateDto** 新增（可选更新标签）：
```csharp
public string Tags { get; set; }
```

### 3. 后端 Service — `ZR.ServiceCore/Services/AiTaskService.cs`

**SubmitTask** — 创建任务时写入 Tags：
- 如果未传 Tags，自动使用当天日期（`DateTime.Now.ToString("yyyy-MM-dd")`）作为默认标签
- 如果传了 Tags，原样保存

**GetMyTaskList** — 查询增加标签过滤：
```csharp
predicate = predicate.AndIF(parm.Tag.IsNotEmpty(), 
    x => x.Tags != null && x.Tags.Contains(parm.Tag));
```

**UpdateTask** — 增加 tags 参数（可选更新）

### 4. 后端 Service接口 — `ZR.ServiceCore/Services/IService/IAiTaskService.cs`
UpdateTask 签名增加 `string tags = null` 参数。

### 5. 后端 Controller — `ZR.Admin.WebApi/Controllers/Ai/AiTaskController.cs`

**Submit** — 从 FormData 接收 `tags` 字段，传入 SubmitTask。

**UpdateTask** — 从 body 接收 tags 字段。

**GetStatus** — 返回中增加 tags 字段。

### 6. 前端 API — `ZR.Vue/src/api/ai/task.js`
`submitTask` 已支持 FormData，前端 append tags 即可，无需改动。

### 7. 前端提交页 — `ZR.Vue/src/views/ai/submit.vue`
在提示词下方新增标签输入区域：
- 一个 `el-input` 输入批次标签（自由文本）
- 一个 `el-date-picker` 选择日期标签（type="date"）
- 已选标签显示为 `el-tag`（可关闭）
- 提交时将标签拼接为逗号分隔字符串传入 FormData

### 8. 前端任务列表 — `ZR.Vue/src/views/ai/list.vue`

**表格**：在「类型」列之后、「提示词」列之前，新增「标签」列，每个标签渲染为 `el-tag`，点击触发过滤。

**过滤栏**：新增标签输入框，支持输入标签文字搜索。

**交互**：点击表格中的标签 → 自动填充到过滤栏 → 触发搜索。

## 验证方式
1. 启动后端 `dotnet watch --project ZR.Admin.WebApi run`
2. 提交任务时选择日期+输入批次，确认数据库 `ai_task.tags` 有值
3. 任务列表显示标签列，点击标签自动过滤出对应任务
4. 筛选栏输入标签文字可搜索
