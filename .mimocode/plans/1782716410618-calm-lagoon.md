# AI图生图功能增强 - 提示词模板 + 任务管理

## 一、需求
1. 提示词模板：用户可保存常用提示词为模板，提交时快速选用
2. 任务列表：提取为模板、删除任务

## 二、变更清单

### 后端
| 文件 | 变更 |
|------|------|
| `ZR.Model/System/Model/AiPromptTemplate.cs` | **新建** 模板实体 |
| `ZR.Model/System/Model/Dto/AiTaskDto.cs` | 新增模板DTO |
| `ZR.ServiceCore/SqlSugar/InitTable.cs` | 注册模板表建表 |
| `ZR.ServiceCore/Services/IAiTaskService.cs` | 新增模板+删除接口 |

| 文件 | 变更 |

## 三、模板实体
```csharp
[SugarTable("ai_prompt_template")]
public class AiPromptTemplate : SysBase {
    long Id;           // 雪花ID
    long UserId;       // 创建人
    string Name;       // 模板名称
    string Prompt;     // 提示词内容
    string FuncType;   // 功能类型: img2img
}
```

## 四、验证
- 提交页：下拉选模板 → 提示词自动填入 → 可手动修改 → 可保存新模板
- 列表页：提取为模板 → 跳转提交页并预填 → 删除任务
- 后端：模板CRUD + 删除任务(需pending/failed状态)
