# AI任务结果图发布到自媒体 — 最终方案

## 步骤1：清理Zr.Admin.NET中的发布相关代码

移除以下文件/代码：
- `ZR.Admin.WebApi/Controllers/Ai/AiTaskController.cs` 中的 `POST /publish`、`GET /publish/accounts`、`GET /publish/music` 三个端点
- `ZR.ServiceCore/Services/AiTaskService.cs` 中的 `PublishToSocial` 和 `GetQianFanSyncBaseUrl` 方法
- `ZR.ServiceCore/Services/IService/IAiTaskService.cs` 中的对应接口
- `ZR.Model/System/Model/Dto/AiTaskDto.cs` 中的 `AiTaskPublishDto`
- `ZR.Vue/src/views/ai/list.vue` 中的发布弹窗、发布按钮、发布相关data/methods
- `ZR.Vue/src/api/ai/task.js` 中的 `publishToSocial`、`getPublishAccounts`、`searchMusic` 函数
- `ZR.Admin.WebApi/appsettings.json` 中的 `QianFanSync` 配置
- `Infrastructure/Model/OptionsSetting.cs` 中的 `QianFanSyncConfig` 类和属性

## 步骤2：Zr.Admin.NET新增结果图查询API

### 修改 `ZR.Admin.WebApi/Controllers/Ai/AiTaskController.cs`
新增端点：
```csharp
[HttpGet("result-images")]
[AllowAnonymous]
public IActionResult GetResultImages([FromQuery] int pageNum = 1, [FromQuery] int pageSize = 20, [FromQuery] string keyword = null)
```

返回已完成任务的ID、提示词、结果图完整URL、标签、创建时间。供QianFan Sync调用。

## 步骤3：QianFan Sync新增AI任务导入功能

### 新增 `frontend/src/components/AiImageImportDialog.vue`
- 弹窗组件
- 连接 `http://localhost:8888/ai/task/result-images` 获取AI任务列表
- 支持分页浏览、关键词搜索
- 多选结果图
- 点击"导入"后，通过QianFan Sync的 `/api/materials/upload` 上传到素材库
- 导入完成后emit事件，父组件将图片添加到发布列表

### 修改 `frontend/src/views/ImagePublish.vue`
- 在 `ImageUploader` 组件旁边增加"从AI系统导入"按钮
- 点击打开 `AiImageImportDialog`
- 导入的图片自动添加到 `currentEditTarget.images`

## 验证方式
1. 重启Zr.Admin.NET后端
2. 启动QianFan Sync前端
3. 打开图集发布页 → 点击"从AI系统导入"
4. 看到AI任务结果图列表 → 多选 → 导入
5. 图片出现在发布列表 → 填写信息 → 发布
